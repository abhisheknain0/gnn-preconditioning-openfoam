# Archived Inference Helpers

This folder preserves older inference diagnostics and benchmark convenience
wrappers that are no longer part of the active thesis benchmark workflow.

Active inference code remains one level up in `gnn_preconditioner/inference/`.
Use the current curated benchmark docs under `gnn_preconditioner/benchmarks/`
for thesis-facing run commands and evidence.

Archived here:

- old rollout/noise plotting helpers,
- old per-timestep log parser used by the steady-consistency check,
- old 10-case benchmark convenience wrappers,
- old case-011 rollout-step sweep,
- old steady-consistency wrapper.
